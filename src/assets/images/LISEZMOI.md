# Images du jeu

Images du jeu, dans le sous-dossier indiqué (`personnages/`, `decors/`, `objets/`), sous le nom exact attendu par `IMAGES` dans `src/view/assets.ts` (ex. `objets/voyant_vert.png`). Une image absente est remplacée par une forme provisoire.

Les planches de référence, le journal de production (prompts et modèles utilisés) et les repères mesurés sur les images sont dans `art/`. Quand une image est remplacée, mesurer à nouveau ses repères (`art/reperes.md`) et reporter les valeurs dans le code.
